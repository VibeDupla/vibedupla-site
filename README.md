# Site institucional VibeDupla

Versão estática pronta para publicação no GitHub Pages.

## Publicação

1. Envie todos os arquivos e a pasta `assets` para a raiz do repositório.
2. No GitHub, acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main`, pasta `/ (root)` e clique em **Save**.

O arquivo inicial é `index.html`. O site não exige instalação, compilação ou servidor.
